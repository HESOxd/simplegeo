# ТЗ: мастер-модель маскота SimpleGeo — хамелеон-проводник

## Задача

Перерисовать существующего персонажа в вектор и зафиксировать его как единую модель. Сейчас позы сгенерированы по отдельности и расходятся между собой: форма гребня, размер и цвет глаз, число витков хвоста, сторона сумки, направление ремня, число пальцев, наличие текстуры на коже. Нужна одна модель, из которой дальше делаются стикеры, анимация, pixel-спрайт и новые позы.

Референсы — файлы `mascot-*.png` в этой папке и референс-лист персонажа, который есть у владельца бренда.

## Роль персонажа

Проводник по подготовке к ОГЭ по географии. Любопытный, дружелюбный, иногда растерянный: ошибается и находит ответ вместе с учеником. Появляется в навигации, обратной связи, на обложках и в пустых состояниях. Внутри условий задач, учебных карт и схем не появляется.

## Неизменная ДНК

| Элемент | Правило |
|---|---|
| Силуэт | Грушевидное тело, крупная голова, короткие лапы |
| Гребень (шлем) | Округлый, без острого пика; одна форма во всех ракурсах |
| Глаза | Большие «турели», белок тёплый светлый, радужка тёпло-коричневая, зрачок чернила |
| Хвост | Спираль 2,5 витка, закручен всегда. Исключение — эмоция «почти»: полуразвёрнут |
| Кожа | Изолинии: тот же шаг и толщина, что в фирменном паттерне; каждая пятая линия чуть темнее |
| Снаряжение | Компас-медальон на груди. Ремень через левое плечо к правому бедру. Сумка на правом бедре |
| Кисть | 4 пальца |

## Техника

- Вектор (SVG + исходник Figma или AI).
- Плоские заливки + одна тень. Без глянца, бликов-градиентов и объёмного «3D».
- Контур `#1C211D`, две толщины: внешний силуэт толще, внутренние линии тоньше. Толщина задаётся долей высоты персонажа, чтобы не «плыть» при масштабе.
- Текстура изолиний — отдельным слоем, который можно выключить для мелких размеров.

## Что сдать

1. Лист разворотов: спереди, 3/4, профиль, сзади.
2. 8 эмоций: привет · подсказка (указывает) · поиск (лупа) · думает · верно (радость) · почти (растерянность) · празднует серию · спит (пустое состояние).
3. 4 уровня детализации:
   - полная поза (от 160 px);
   - поза для обратной связи (48–120 px) — упрощённая текстура;
   - голова-иконка (24–64 px) — без текстуры, без снаряжения;
   - pixel-спрайт 16×16 и 32×32 — палитра не больше 8 цветов.
4. Вариант хвоста по природным зонам (опционально): пустыня `#D9A441`, лес `#2F7D46`, тундра `#9CCFD8`, океан `#1F7F8E`.
5. PNG с прозрачным фоном для каждой эмоции (1024 px по высоте) и SVG.

## Нельзя

- Менять пропорции, форму гребня, число витков хвоста и пальцев между позами.
- Добавлять одежду, аксессуары, надписи, кроме компаса и сумки.
- Делать персонажа «милым малышом»: аудитория — 14–16 лет.
- Придавать сходство с известными мультперсонажами-хамелеонами. Отличие держится на снаряжении и изолиниях на коже — их не уменьшать.
