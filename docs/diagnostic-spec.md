# Мини-диагностика ОГЭ — спецификация (v2, 24.09.2026)

Цель: бесплатный лид-магнит. Ученик за ~10–12 минут получает карту слабых
блоков и кнопку «Разобрать результат с Юрием» → Telegram с готовым текстом.
Бэкенда нет (статика на S3) — всё в браузере и в адресной строке.

Концепция v2 (решения владельца): Agent Store `docs/diagnostic-v2-concept.md`,
разбаловка SPEC 2027 — `docs/oge-2027-points-extract.md` (в репо/store).

## Маршруты

- `/tasks/diagnostic` — старт → прохождение → результат → (опц.) разбор.
- `/tasks/diagnostic/result?r=<код>` — результат по ссылке (для «поделиться»
  и для сообщения в Telegram). Открывается без прохождения; разбора эталонов
  нет (в `r` только блоки) — CTA «пройти диагностику».
- `/diagnostic` — короткий алиас → redirect на `/tasks/diagnostic`
  (для видео и постов: simplegeo.ru/diagnostic).

## Вход

- Первая карточка на главной `/tasks`, над «Варианты недели»:
  заголовок «Узнай свои слабые места», подпись «13 заданий · ~10–12 минут ·
  ответы после», маскот `welcome.png`.
- В меню НЕ добавлять.

## Сборка набора — `src/diagnosticBuilder.js` (v2)

Использует `buildPositionPools(TASKS)` из `positionClassifier.js`.
Эссе (позиции 12, 29, 30) и **№9** (линейка) не берём. Модель выбора — **B′**:
случайный пул + prefer `single`/`multi` где возможно; топо — общий `groupId`.

| Ключ блока | Название в отчёте | Позиции пула | Заданий | examPrimaryMax (SPEC) |
|---|---|---|---|---|
| `topo` | Топография (план местности) | **10, 11** (всегда оба, один `groupId`) | **2** | **2** |
| `maps` | Карты, координаты, часовые пояса | 7, 26 | 2 | 2 |
| `climate` | Атмосфера и климат | 5, 6, 16, 17, 18 | **2** | 5 |
| `nature` | Природа России | 4, 8, 14, 15, 22 | **2** | 5 |
| `people` | Население и хозяйство России | 13, 19, 23, 24, 25 | **2** | 5 |
| `world` | Мир: материки и страны | 1, 3, 20, 21, 27 | **2** | 5 |
| `regions` | Регионы России по тексту | 2, 28 | **1** | 2 |

Правила: внутри блока позиции без повторов; `groupId` уникален во всём наборе;
порядок показа — по возрастанию позиции. **Всего 13 заданий.** №12 не включаем.

`examPrimaryMax` — сумма макс. первичных баллов позиций **пула** блока по SPEC
2027 (макс. КИМ = 31). Это ориентир слоя 2 / тай-брейк, не «потерянные баллы».

## Прохождение

`VariantRunner` с `revealMode="deferred"`: без вердикта и эталона по ходу,
кнопка «Дальше» / «К итогам», прогресс «задание k из 13» без счётчика «Верно».
`persistKey = "diag:v2:<дата>"` (старый `diag:<дата>` не подхватываем).
Обычные Variant/Weekly не передают `revealMode` → режим `"instant"` как раньше.

## Результат — `DiagnosticResult`

Данные: `{ date, blocks: { topo: [верно, всего], ... }, version? }`.

Светофор: зелёный — все верно; жёлтый — одна ошибка; красный — две и больше.
Для `regions` (total=1): 1/1 green, 0/1 red.

Экран:
1. Маскот `finish.png` + счётчик **N из 13** + спокойная фраза про 1–2 слабых
   блока (или «сильных просадок нет» / жёсткий 0/13 = план, не приговор).
   **Нет** hero «На экзамене это до N баллов».
2. Семь карточек, red → yellow → green. На карточке: название, «задания №…»,
   «{верно}/{всего}», мелкая подпись слоя 2 с `examPrimaryMax`, кнопка
   «Тренировать №N» → `/tasks/by-number?pos=N`.
3. Прогноза оценки нет.
4. CTA «Разобрать результат с Юрием» → Telegram (`TELEGRAM_CONTACT`);
   при 0/13 primary — «Тренировать №N», Telegram вторично.
5. «Разобрать задания» — разбор эталонов (только после прохождения, когда
   есть `answers[]`). По ссылке `?r=` — предложение пройти диагностику.
6. «Пройти ещё раз», «Скопировать ссылку».

## Код результата в адресе

- **Encode** всегда `v2|YYYY-MM-DD|topo:1/2|maps:2/2|…` (base64url).
- **Decode** понимает **v1** (старые totals: topo 3, …, regions 2) и **v2**.
  Битый код → `NotFound`.

## localStorage

- Прогресс квиза: `diag:v2:<дата>`.
- История: `diag:history` — `{ version: 2, date, blocks }`. Сравнение с
  предыдущей попыткой по ключам блоков (мягкая пометка лучше/хуже).

## Метрика (когда появится счётчик)

Цели: `diag_start`, `diag_finish`, `diag_review_open`, `diag_cta_tg`, `diag_share`.

## Тесты (vitest)

- сборщик: 13 заданий, нет pos 9 / эссе, topo 10+11 один `groupId`, нет
  повторов id/`groupId`;
- светофор: total=2 и total=1; total=3 для совместимости формулы;
- encode/decode v2 обратимо; decode v1 читает старые ссылки; битая → null.

## Не делаем в этой версии

PDF-отчёт, форма с телефоном, прогноз оценки, вход по аккаунту, диагностика
эссе / №9 / №12, таймер, герой «до N баллов».
