# Мини-диагностика ОГЭ — спецификация (22.09.2026)

Цель: бесплатный лид-магнит. Ученик за ~20 минут получает карту слабых блоков
и одну кнопку «Разобрать результат с Юрием» → Telegram с готовым текстом.
Бэкенда нет (статика на S3) — всё в браузере и в адресной строке.

## Маршруты

- `/tasks/diagnostic` — старт → прохождение → результат.
- `/tasks/diagnostic/result?r=<код>` — результат по ссылке (для «поделиться»
  и для сообщения в Telegram). Открывается без прохождения.
- `/diagnostic` — короткий алиас → redirect на `/tasks/diagnostic`
  (для видео и постов: simplegeo.ru/diagnostic).

## Вход

- Первая карточка на главной `/tasks`, над «Варианты недели»:
  заголовок «Узнай свои слабые места», подпись «20 заданий · 20 минут ·
  отчёт по блокам», маскот `welcome.png`.
- В меню НЕ добавлять.

## Сборка набора — `src/diagnosticBuilder.js`

Использует `buildPositionPools(TASKS)` из `positionClassifier.js`.
Эссе (позиции 12, 29, 30) не берём — только автопроверяемые типы.

| Ключ блока | Название в отчёте | Позиции | Заданий | Баллов на ОГЭ |
|---|---|---|---|---|
| `topo` | Топография (план местности) | 9, 10, 11 | 3 | 3 (+1 за №12) |
| `maps` | Карты, координаты, часовые пояса | 7, 26 | 2 | 2 |
| `climate` | Атмосфера и климат | 5, 6, 16, 17, 18 | 3 | 5 |
| `nature` | Природа России | 4, 8, 14, 15, 22 | 3 | 5 |
| `people` | Население и хозяйство России | 13, 19, 23, 24, 25 | 3 | 5 |
| `world` | Мир: материки и страны | 1, 3, 20, 21, 27 | 3 | 5 |
| `regions` | Регионы России по тексту | 2, 28 | 2 | 2 |

Правила выбора: внутри блока позиции берутся без повторов (shuffle
позиций блока, первые N), из пула позиции — случайное задание,
`groupId` не повторяется во всём наборе. Порядок показа — по возрастанию
позиции (как в реальном варианте). Всего 19 заданий.

## Прохождение

Переиспользовать `VariantRunner` (или его внутренности) — нужен только
свой экран результата. Прогресс — `persistKey = "diag:<дата>"`.
Таймер не нужен; показать «задание 7 из 19».

## Результат — `DiagnosticResult`

Данные: `{ date, blocks: { topo: [верно, всего], ... } }`.

Светофор блока: зелёный — все верно; жёлтый — одна ошибка; красный —
две и больше (для блоков из 2 заданий: 1 ошибка = жёлтый, 2 = красный).

Экран:
1. Маскот `finish.png` + одна фраза: «Слабее всего — {два худших блока}.
   На экзамене это до {сумма баллов этих блоков} баллов».
2. Семь карточек, отсортированы: красные → жёлтые → зелёные. На карточке:
   название, «задания №…», «{верно}/{всего}», кнопка «Тренировать №N» →
   `/tasks/by-number?pos=N` (в `ByPosition.jsx` добавить чтение `pos` из
   query: сразу экран `setup` для этой позиции).
3. Никакого прогноза оценки — только «баллы под риском».
4. Кнопка-CTA (основная, градиентная): «Разобрать результат с Юрием» →
   `https://t.me/<USERNAME>?text=<encodeURIComponent(текст)>`, текст:
   «Привет! Прошёл диагностику на simplegeo. Слабые блоки: топография
   (1/3), климат (1/3). Результат: https://simplegeo.ru/tasks/diagnostic/result?r=…».
   **`<USERNAME>` — личный аккаунт Юрия, не канал** (ссылка `?text=` работает
   только для пользователей/ботов; в `About.jsx`/`Course.jsx` сейчас стоит
   канал `prostayageo`).
5. Вторая кнопка: «Пройти ещё раз» (новый набор).
6. Ссылка «Скопировать ссылку на результат».

## Код результата в адресе

`r` = base64url от строки `v1|YYYY-MM-DD|topo:1/3|maps:2/2|…`. Без личных
данных. Страница `/result` рендерит тот же `DiagnosticResult` из кода;
при битом коде — `NotFound`.

## localStorage

Ключ `diag:history` — массив результатов (дата + блоки). При показе
результата, если есть предыдущий, добавить строку «В прошлый раз: …» на
карточках, где стало лучше/хуже. Это задел под личный кабинет.

## Метрика (когда появится счётчик)

Цели: `diag_start`, `diag_finish`, `diag_cta_tg`, `diag_share`.

## Тесты (vitest, рядом с существующими)

- сборщик отдаёт 19 заданий, все позиции блока различны, нет эссе,
  нет повторов `groupId`;
- светофор: 3/3 → green, 2/3 → yellow, 1/3 и 0/3 → red, 1/2 → yellow, 0/2 → red;
- кодирование/декодирование `r` — обратимо, битая строка → null.

## Не делаем в этой версии

PDF-отчёт, форму с телефоном, прогноз оценки, вход по аккаунту,
диагностику эссе, таймер.
