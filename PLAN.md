# SimpleGeo — план и спецификация

Актуально на **22 сентября 2026**. Это главный документ проекта: что сайт уже
умеет (часть «Спецификация») и что делаем дальше (часть «План»). Если что-то
поменялось в коде — правим и этот файл, иначе он через месяц станет таким же
устаревшим списком, каким был раздел «Дальше по плану» в README.

## 0. Что это и для кого

**SimpleGeo** — бесплатный тренажёр подготовки к **ОГЭ по географии** (9 класс).
Сайт: `simplegeo.ru`.

Почему ОГЭ, а не ЕГЭ: ОГЭ по географии сдают ~736 тыс. девятиклассников против
~24 тыс. на ЕГЭ, а сильные эксперты рынка сидят на ЕГЭ — на ОГЭ конкуренция
слабее. Подробности рынка — в отдельном исследовании
`~/Downloads/compass_artifact_wf-cf7a49e5-0a93-5c36-adb2-a679e52d63f1_text_markdown.md`
(сентябрь 2026, >50 тем контента, хуки, офферы, воронки).

Модель: бесплатный тренажёр привлекает трафик → Telegram-канал
[`prostayageo`](https://t.me/prostayageo) → платные продукты (сейчас на сайте
один — курс-гайд, 1499 ₽).

| `sequence` | 455 | последовательность / соответствие |

Поля задания: `id`, `type`, `q`, `sec`, `kes`, `image`, `options`, `correct`.
Разделов курса — 7 (`SECTIONS` в том же файле), самый большой — «Население и
хозяйство России» (1018 заданий).

`pipeline/01…08_*.py`). Менять сами задания и ответы можно только там, потом
перегенерировать `src/data.js` скриптом `06_generate_data_js.py`.

Отдельно: **`src/data/demo2027.js`** — официальный демо-вариант ОГЭ 2027
(проект ФИПИ), 35 заданий, картинки лежат в `public/demo2027/`.

Общая логика прохождения варианта вынесена в **`src/VariantRunner.jsx`** —
её переиспользуют «полный вариант», «варианты недели» и мини-диагностика
(через `renderResult` и `revealMode="deferred"`). Общие UI-кирпичики
(`Shell`, `TaskCard`, `ProgressBar`, кнопки) экспортируются из `Trainer.jsx`.
Сборка набора диагностики — **`src/diagnosticBuilder.js`** (спека
`docs/diagnostic-spec.md`, v2).

### 1.4 Ключевая логика

- **`src/positionClassifier.js`** — источник истины: какое задание банка может
  стоять на позиции N (1–30). Построен по трём реальным вариантам с sdamgia +
  спецификации ФИПИ 2026. Все 30 позиций имеют непустой пул.
- **`src/variantBuilder.js`** — сборка «честного» варианта. Пять групп позиций
  делят общий контекст и берутся целиком: 9–12 (топоплан), 5–6 (погодная карта),
  16–17 (данные наблюдений), 23–24 (демография), 28–30 (текст).
- **`src/utils.js`** — проверка ответа (`isTaskRight`), нормализация текста
  (ё/е, пробелы, регистр), детерминированный генератор случайных чисел
  `seededRng` для вариантов недели.
- **`scripts/generateWeeklyVariants.js`** — раз в неделю (понедельник 06:00 МСК)
  собирает 5 непересекающихся вариантов, коммитит `public/weekly-variants.json`
  прямо в `main` и деплоит сайт. После его запуска локальную копию нужно
  подтянуть (`git pull`), иначе она отстаёт на неделю.

### 1.5 Что хранится у пользователя

Только **localStorage, на его собственном устройстве**. Никуда не отправляется,
мне не видно:

- прогресс по полному варианту и вариантам недели (`VariantRunner`);
- прогресс и история мини-диагностики (`diag:v2:<дата>`, `diag:history`);
- прогресс по демо-2027 (`demo2027-progress-v3`).

Везде обёрнуто в `try/catch` — в приватном режиме просто не сохраняется.

### 1.6 Сборка и деплой

```bash
npm install     # один раз
npm run dev     # локально → http://localhost:5173
npm run build   # собрать в dist/
npm run preview # посмотреть собранное
```

Деплой автоматический: `git push` в `main` → GitHub Actions собирает и
заливает `dist/` в S3-контейнер Selectel. `index.html` и
`weekly-variants.json` заливаются с `no-cache`, всё остальное — на год
(`immutable`), потому что у файлов хэш в имени.

Секреты живут в GitHub Secrets: `S3_KEY_ID`, `S3_SECRET`, `S3_BUCKET`,
`S3_ENDPOINT`. В коде их нет и быть не должно.

### 1.7 Тесты

```bash
npm test         # прогнать один раз
```

Покрыта вся логика, которая может молча испортить результат ученика:

| Файл | Что проверяет |
|---|---|
| `tests/utils.test.js` | Проверка ответа и нормализация текста |
| `tests/dataset.test.js` | Целостность банка: ответы, индексы, картинки, дубли |
| `tests/variantBuilder.test.js` | Структура варианта, сцепленные блоки, воспроизводимость |

Все зелёные (включая `diagnostic`). Тесты с пометкой `[РЕГРЕССИЯ]` сторожат уже починенные
дефекты — если такой покраснел, вернулась старая ошибка, и чинить надо код
или данные, а не тест.

**Что нашли и починили 22.09.2026:**

| Было | Стало |
|---|---|
| В 10 заданиях минус записан длинным тире — верный ответ ученика засчитывался как ошибка | `norm()` приводит все виды тире к дефису, данные вычищены |
| `norm()` стирала десятичную запятую: «14» засчитывалось вместо «1,4» | Запятая между цифрами сохраняется, «1,4» и «1.4» — один ответ |
| `fipi-46AAB9`: ответ `«,3»` — при парсинге потерялся ведущий ноль | Восстановлено по графику ФИПИ: 11,5 − 11,2 = `0,3` |
| `fipi-1DE3F0`: тире, пробел в разрядах и `format: word` вместо `number` | `-12102`, `number` |
| 2 пары полностью одинаковых заданий под разными id | Лишние удалены, в банке 2353 задания |

### 1.8 Чего в системе нет — и это сознательно

- **Нет бэкенда и базы.** Всё считается в браузере. Значит: нет аккаунтов,
  нет синхронизации прогресса между устройствами, нет серверной статистики.
- **Нет аналитики.** Сейчас я вообще не знаю, сколько человек заходит.
- **Нет куки.** Ни одной — ни своей, ни чужой.
- **Нет приёма платежей на сайте.** Курс продаётся через Telegram вручную.
- **Нет тестов интерфейса.** Кнопки и экраны проверяются глазами на localhost
  перед коммитом. Логика при этом покрыта тестами — см. 1.7.

## 2. План

### 2.1 Сейчас в работе — аналитика и юридическая обвязка

Повод: до конца сентября начинаю записывать видео про сайт, придут люди.
Без счётчика я не увижу ни сколько их, ни куда они уходят.

Три вещи идут одним куском, потому что счётчик без баннера и политики —
это уже нарушение:

1. **Яндекс.Метрика** — счётчик с анонимизацией IP.
2. **Баннер согласия** — с раздельными кнопками «принять» / «отклонить»
   (поправка 156-ФЗ, действует с 01.09.2025: согласие должно быть отдельным
   осознанным действием, а не «продолжая пользоваться, вы согласны»).
3. **Политика обработки персональных данных** — отдельная страница, ссылка
   в подвале.

**Заблокировано на мне.** Чтобы это доделать, нужно от меня три вещи:
номер счётчика Метрики, мой юридический статус (физлицо / самозанятый / ИП /
ООО) и контактный email для политики.

4. **Уведомление в Роскомнадзор** (ст. 22 152-ФЗ) — подаётся лично через
   Госуслуги на `pd.rkn.gov.ru`, это может сделать только человек. Можно
   отложить на пару недель после запуска счётчика, но не забыть.

### 2.2 Дальше — то, что двигает продукт

- **Мини-диагностика v2** — в коде (24.09.2026): 13 заданий по 7 блокам
  (topo = только 10+11 из одного `groupId`, без №9), режим deferred
  (ответы после финиша), светофор, осторожный слой баллов
  (`examPrimaryMax` из SPEC 2027), ссылка `?r=` (encode v2, decode v1+v2),
  разбор заданий после итога, CTA «Разобрать с Юрием». Личный Telegram —
  `hesoxd` в коде; (позже) PDF-доводчики по слабым блокам.
- **Платные доводчики** — короткие PDF-разборы по западающим блокам
  (топография 9–12, координаты, климатограммы). Это **контент, а не код**:
  фактическую точность проверяю я сам как предметник, помощь — черновик и
  структура.
- **Формат демо-2027 для вариантов недели** — сплошной свиток вместо
  пошаговых экранов. Отложено сознательно, не начато.

### 2.3 Отложено — вернуться, когда будет время делать нормально

- **Личный кабинет с прогрессом.** Хорошая фича и потенциально платная, но
  сейчас бэкенда нет вообще. Делать авторизацию за неделю к запуску видео —
  это способ получить дыру в безопасности, а не фичу. Нужна отдельная сессия
  под бэкенд.
- **Автопостинг в Telegram.** Решено делать в два этапа: сначала только
  генерация черновика поста + отправка мне на проверку, автопубликация в канал
  через Bot API — вторым этапом, через неделю-две после того, как станет видно,
  что контент заходит.

## 3. Юридический статус (152-ФЗ) — что проверено

Проверено по первоисточникам (consultant.ru, публикации РКН), а не по
автоматическому «сканеру соответствия», который присылал отчёт — в нём было
две фактические ошибки (сервер приписан Cloudflare, хотя он в Selectel; куки-
баннер требовали при нулевых куках).

| Требование | Статус |
|---|---|
| Данные хранятся в России (ст. 18 152-ФЗ) | ✅ Selectel, РФ |
| Утечка IP на зарубежные серверы через шрифты | ✅ Закрыто 21.09.2026 — самохостинг |
| Политика обработки ПДн (ст. 18.1) | ❌ Нет — делаем в 2.1 |
| Согласие на обработку (ст. 9 + 156-ФЗ) | ❌ Нет баннера — делаем в 2.1 |
| Уведомление в РКН (ст. 22) | ❌ Не подано — пункт 4 в 2.1 |
| Куки-баннер | Пока не требуется: куков на сайте нет. Станет нужен вместе с Метрикой |

Ссылка «ст. 23 ФЗ-149», которая встречалась в присланных материалах, —
несуществующая: 149-ФЗ заканчивается статьёй 18. Скорее всего спутали со
статьёй 23 закона 152-ФЗ (она про полномочия самого Роскомнадзора).

## 4. Как ведём работу

- **Ничего не коммитится и не пушится без моего явного «да»** на каждый раз.
  Сначала показ на localhost, потом вопрос, потом коммит.
- **Секреты никогда не идут через переписку** — токены и ключи я ввожу сам.
- **Задания и ответы правятся только в `fipi_parser/`**, потом перегенерация
  `src/data.js`. Править `data.js` руками нельзя — затрётся.
- Отчёты по сессиям — `~/.claude/open-steps/reports/simplegeo/latest.md`.
