# SimpleGeo — тренажёр ОГЭ по географии

Статический сайт на React + Vite. Банк заданий ФИПИ (2353 шт): одиночный выбор, выбор нескольких, короткий ответ, последовательность, развёрнутый ответ. Фильтр по разделам, полные варианты, тренировка по номеру задания.

**Что сайт умеет и что делаем дальше — в [PLAN.md](PLAN.md).** Этот файл — только про то, как запустить и задеплоить.

---

## Локальный запуск

Нужен установленный Node.js (версия 22.12 или новее). Проверить: `node --version`.

```bash
npm install      # поставить зависимости (один раз)
npm run dev      # запустить локально → открой http://localhost:5173
npm run build    # собрать продакшн-версию в папку dist/
npm run preview  # посмотреть собранную версию локально
```

Всё, что видит пользователь, собирается в папку **`dist/`** — именно её содержимое заливается на хостинг.

## Структура

```
simplegeo/
├── index.html            точка входа
├── src/
│   ├── main.jsx          запуск React + шрифты
│   ├── App.jsx           маршруты и верхнее меню
│   ├── pages/            экраны (Trainer, Variant, ByPosition, Weekly, Demo2027, About, Course)
│   ├── VariantRunner.jsx общий движок прохождения варианта
│   ├── variantBuilder.js сборка варианта по структуре реального ОГЭ
│   ├── positionClassifier.js  какое задание может стоять на позиции 1-30
│   ├── data.js           банк заданий (2353 шт, автогенерация)
│   └── index.css         подключение Tailwind
├── scripts/              генерация «вариантов недели»
├── package.json          зависимости и команды
└── vite.config.js        настройки сборки
```

Задания и ответы правятся **не здесь**, а в соседнем репозитории `~/Desktop/fipi_parser/` (Python-пайплайн), оттуда перегенерируется `src/data.js`. Править `data.js` руками нельзя — затрётся при следующей генерации.

## Деплой на simplegeo.ru (Selectel, объектное хранилище S3)

Зарубежные хостинги (Vercel/Netlify/Cloudflare) в РФ нестабильны — используем Selectel, там же где домен.

### Шаг 1. Создать контейнер
1. Панель Selectel → Объектное хранилище → создать **публичный** контейнер (тип: для статических сайтов).
2. В настройках контейнера указать индексную страницу `index.html`.

### Шаг 2. Залить сайт
1. Локально: `npm run build`.
2. Загрузить **всё содержимое папки `dist/`** в контейнер (через веб-панель перетаскиванием, либо через S3-клиент — см. ниже).
3. Сайт откроется по служебному домену контейнера — проверь, что работает.

### Шаг 3. Привязать домен
1. В контейнере → вкладка «Домены» → добавить `simplegeo.ru` (и/или `www.simplegeo.ru`).
2. Selectel → DNS-хостинг для `simplegeo.ru` → добавить запись по инструкции, которую покажет панель при привязке (обычно CNAME на домен контейнера).
3. Включить HTTPS для домена (в панели Selectel — выпуск сертификата).
4. Подождать обновления DNS (от 10 минут до нескольких часов).

### Автозаливка
Обычно ничего делать не нужно: `git push` в `main` сам собирает и заливает сайт
(`.github/workflows/deploy.yml` → `scripts/deploy-s3.sh`). Скрипт сжимает файлы и
ставит правила кэша — голый `aws s3 sync` этого не делает.

Если всё же надо залить руками — тем же скриптом (нужен aws-cli с ключами Selectel S3
в переменных окружения `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`):
```bash
npm run build && S3_BUCKET=ИМЯ_КОНТЕЙНЕРА S3_ENDPOINT=https://s3.storage.selcloud.ru SITE_URL=https://www.simplegeo.ru bash scripts/deploy-s3.sh
```
Точный endpoint и ключи бери в панели Selectel. Ключи держи только у себя, в код не коммить.
